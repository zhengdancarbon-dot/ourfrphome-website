# Generated SEO Reports

`pnpm seo:report` creates the current `weekly-report.md`, `weekly-dashboard.html`, `six-core-performance.csv`, `country-performance.csv`, `decision-queue.csv`, `opportunities.csv` and `cannibalization.csv` from imported evidence.

The dashboard focuses on Woven Fabric, Multiaxial NCF, UD Fabric, 3K Carbon Fiber Laminate Sheet, Yarn & Tow and Structural Strengthening. It deliberately reports unavailable data rather than inventing metrics, rankings, conversions or recommendations.

Generated files are ignored by Git. Run `pnpm seo:data:validate && pnpm seo:data:import && pnpm seo:report` after each reviewed weekly export.
