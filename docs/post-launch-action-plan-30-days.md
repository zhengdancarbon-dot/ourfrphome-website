# Post-Launch SEO / GEO 30-Day Action Plan

Production domain: https://www.myfrphome.com

Last prepared: 2026-07-03

## Objective

Build stable search visibility, answer-engine visibility and RFQ conversion tracking after launch without changing the current URL structure or making unsupported claims.

## Week 1: Baseline And Submission

### Monitoring

- Confirm Google Search Console property access.
- Confirm Bing Webmaster Tools property access.
- Confirm `https://www.myfrphome.com/sitemap.xml` is submitted in both tools.
- Confirm `https://www.myfrphome.com/robots.txt` references the sitemap.
- Request indexing for priority URLs in `docs/priority-url-submission-list.md`.
- Record baseline:
  - Indexed pages.
  - Sitemap status.
  - Search impressions.
  - Clicks.
  - Top queries.
  - Top landing pages.
  - RFQ submissions.
  - WhatsApp clicks.
  - Email clicks.
  - Catalog downloads.

### Technical Checks

- Check homepage, products, catalog, applications, quality and contact pages return `200`.
- Check all product detail pages return `200`.
- Check all technical center pages return `200`.
- Run a basic broken-link crawl.
- Check Core Web Vitals / PageSpeed for homepage and product pages.

### Analytics

- Confirm GA4 Realtime receives traffic.
- Confirm events:
  - `rfq_submit`
  - `whatsapp_click`
  - `email_click`
  - `catalog_download`
- Confirm inquiry emails are received.
- Microsoft Clarity is not currently installed; add only after a real Clarity project ID is provided.

## Week 2: Index Coverage And Conversion Review

### Monitoring

- Review GSC Indexing > Pages.
- Identify priority pages still not indexed.
- Review Bing sitemap and URL submission status.
- Check GA4 traffic sources and conversion events.
- Compare inquiry count with email inbox count.

### Content Review Without Large Changes

- Do not rewrite pages broadly.
- Only prepare notes for content improvements based on real query data.
- Prioritize gaps around:
  - 3K twill carbon fiber fabric.
  - UD carbon fiber fabric.
  - Carbon fiber prepreg.
  - Carbon fiber yarn and tow.
  - Milled carbon fiber powder.
  - Chopped carbon fiber.
  - Carbon fiber plates and tubes.
  - Custom carbon fiber products.

## Week 3: GEO / AI Visibility Review

- Run the questions in `docs/ai-visibility-test-questions.md`.
- Record whether FRP HOME is mentioned.
- Record whether `https://www.myfrphome.com` is cited.
- Record which pages are cited.
- Mark incorrect or missing product facts.

## Week 4: Optimization Plan And Reporting

### Weekly Report

- Complete `docs/weekly-seo-geo-report-template.md`.
- Compare baseline against current week.
- Identify:
  - Best-performing pages.
  - Under-indexed priority pages.
  - Product queries with impressions but low CTR.
  - RFQ conversion gaps.
  - AI visibility gaps.

### Technical Follow-Up

## Standing Guardrails

- Keep URL slugs stable.
- Do not make large content changes without confirmation.
- Do not invent certifications.
- Do not claim authorization without real authorization documents.
- Do not add annual capacity without verified source data.
- Do not add test reports without real documents.
- Do not add customer cases unless approved real cases are provided.
- Do not add military, weaponized drone, missile or combat UAV wording.
- Keep compliance and end-use review language active.
