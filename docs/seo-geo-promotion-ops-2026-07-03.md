### IndexNow

IndexNow is useful for future page updates because it can notify participating engines directly when URLs change. Do not enable it until an IndexNow key is generated and hosted at the site root. Recommended implementation:

1. Generate an IndexNow key.
2. Add a static key file at `public/<key>.txt`.
3. Add a small script or manual command for changed URL submission.
4. Submit only canonical URLs on `https://www.myfrphome.com`.
