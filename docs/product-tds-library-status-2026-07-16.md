# FRP HOME Product TDS Library Status

Date: 2026-07-16

## Publishing standard

- FRP HOME letterhead, current domain and current inquiry contact are required.
- Published numerical values must be traceable to a user-provided or local source document.
- Third-party grades must remain identified as supplier-origin references; FRP HOME manufacture or official authorization is not implied.
- Website examples are not batch certificates. Final specification, test method, tolerance and COA requirements remain subject to quotation and order confirmation.
- Web research may be used to check standards, terminology and document structure, but competitor values must not be republished as FRP HOME product data.
- Unsupported certifications, capacity, customer cases, test reports and sensitive end uses are excluded.
